【怎么打开：三种方式】
--------------------------------------------------------

① 直接双击 index.html（零门槛）
   可用：变阻器交互、六档形象、特效音效、演示文案对话
   不可用：真·AI 对话（浏览器禁止本地文件直连接口）

② 本机起服务（推荐，能体验真·AI 对话）
   1. 装好 Python 后，在本文件夹打开命令行执行：
        python -m http.server 8899
   2. 浏览器打开  http://127.0.0.1:8899
   3. 页脚「回复源设置」→ 选 Agnes AI 真实对话
   4. 填入自己的 API Key（agnes-ai.cn 免费注册，
      模型 agnes-3.0-flash 现阶段免费）→ 保存
   5. 拖滑杆换档位，直接跟 AI 大爷聊
   ※ Key 只存你自己浏览器，不写码不上传

③ 部署成公开网址（✅ 已完成，此处留作参考）
   本项目已双线上线（2026-10-06）：
     主站   https://tianjin-daye.pages.dev （Cloudflare Pages）
     备用线 https://care-art.github.io/tianjin-daye/ （GitHub Pages）
   线上默认"演示文案"模式（稳定零失败）。
   体验真·AI 对话：
     1. agnes-ai.cn 免费注册，创建 API Key（agnes-3.0-flash 免费）
     2. 线上页面 → 页脚「回复源设置」→ 选 Agnes AI 真实对话
     3. 粘贴 Key → 保存，立即生效（Key 只存你自己浏览器）
   ※ 注：曾尝试云端代理替访客藏 Key，但 Agnes 风控会拦截
     云端服务器出口，故采用"访客自填免费 Key"方案。
     deploy/worker.js 保留备未来使用。

【怎么玩（30秒上手）】
--------------------------------------------------------
 1. 拖中间的滑动变阻器：往左=捧哏（温和），往右=开怼（损到底）
    形象、音效、特效随档位实时变化
 2. 下方输入框说话点发送：AI 大爷按当前档位用天津话回你
 3. 每条气泡旁标注当时档位与损度，方便录屏展示"输出可控性"
 4. 页脚「人设 Prompt」：查看/编辑/复制 AI 人设，改完立即生效

【常见问题】
--------------------------------------------------------
 · 发消息没反应？mock 模式点发送即可；真 AI 模式确认 Key 已填
 · 比赛要求扣子(Coze)？页脚切换到 Coze，填 PAT 和 bot_id 即可
 · 手机打字换行误发送？已处理：触屏 Enter 只换行，按按钮发送
 · 图片会丢吗？img 文件夹随包一起发就不会丢；
   就算丢了，页面自动回退内置手绘形象
